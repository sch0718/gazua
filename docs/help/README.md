# 가즈아 도움말

<!-- 이 파일은 corepack pnpm build:motion으로 생성합니다. 문구는 scripts/motion/help-pages.mjs에서 고칩니다. -->

메뉴마다 실제 화면 흐름을 움직이는 그림으로 보여 줍니다. 서비스 소개는 [README](../../README.md)에 있습니다.

| 메뉴 | 이렇게 써요 |
| --- | --- |
| [비교 차트](compare.md) | 그룹 고르기 → 기간 바꾸기 → 지표 고르기 → 순위 보기 |
| [종목 추가](add.md) | `＋ 종목 추가` 누르기 → 이름·초성으로 찾기 → ＋로 담기 → ✓ 다시 누르면 빼기 |
| [그룹 관리](groups.md) | 새 그룹 만들기 → 이름·순서 바꾸기 → 토스에서 가져오기 → 조건으로 골라 새 그룹 |
| [매매 규칙 시뮬레이션](simulate.md) | 새 전략 만들기 → 매수 규칙 정하기 → 매도 규칙 정하고 실행 → 결과 보기 |
| [선정 기준 검증](criteria.md) | 시장 데이터 가져오기 → 조건 켜기 → 고를 개수·재선정 정하고 실행 → 결과 비교 |
| [내 성과](performance.md) | 벤치마크 고르기 → IRR 비교 → 평가금액 + 회수액 → 종목별 기여도 |
| [설정과 연결](settings.md) | 공급자 고르기 → 프록시와 키 넣기 → 연결 진단 → 키 잠그기 |

그림과 글은 `corepack pnpm build:motion`이 `scripts/motion/help-pages.mjs`로 만듭니다. 화면 문구가 바뀌면 그 파일을 고치고 다시 만드세요.
