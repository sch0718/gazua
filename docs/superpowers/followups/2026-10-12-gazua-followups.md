# 가즈아 — 후속 작업 목록 (2026-10-12)

구현 브랜치 `feat/app-implementation`의 리뷰에서 나왔지만 이번 범위에서 미룬 항목입니다. 실제 API로 확인할 항목은 [live-check.md](../../live-check.md)에 따로 있습니다.

## 정확도
- D1 NXT/통합 모드의 RVOL이 KRX 20일 평균 거래량으로 나눔 → 해당 거래소 일봉 평균을 쓰거나 표기.
- 종목 메타(거래정지 등)를 탭을 연 뒤 다시 받지 않음 → KST 날짜가 바뀌면 만료.
- 한 행 안에서 가격(5초 시세)과 %(60초 캔들)가 최대 1분 어긋남.
- 기간 끝까지 이어지는 거래정지는 마지막 봉 뒤로 띠가 없음(행 배지는 표시됨).
- KIS 토큰 발급 제한(EGW00133) 남은 초 표시는 `Retry-After`가 있을 때만 나옴 → 토큰 매니저의 마지막 발급 시각으로 계산.

## 오류 안내
- 8개 중 한 행의 일시적 연결 오류만으로 `프록시에 연결할 수 없어요` 배너가 뜸 → 다수/전부 실패일 때만.
- 8초 타임아웃은 스펙상 '프록시 미응답'이지만 `응답이 늦어요`로 표시.
- 저장돼 있던 `http://localhost` 프록시 주소를 지울 때 배너가 일반 문구 → 어떤 값이 지워졌는지 표시.
- `sanitizeWatchlists`가 그룹이 모두 깨졌을 때 기본 `내 관심` 그룹 대신 빈 목록을 돌려줌.

## 보안·운영
- 키 포함 내보내기에 확인 대화상자 추가(현재 체크박스 + 안내문).
- 429 수신 시 같은 그룹의 다른 요청도 `Retry-After`만큼 멈추기.
- CI 빌드가 매번 KIS 마스터를 내려받음 → 마지막 universe.json 캐시.
- 프록시: `PROXY_TOKEN` 상수 시간 비교, `cloudflared:latest` 버전 고정, 리다이렉트 시 `x-proxy-token` 전달 방지.
- CI에서 Playwright 브라우저 캐시, e2e 파일 타입 검사(`check:e2e`).

## 접근성·UI
- GroupTabs에 화살표 키 이동(roving tabindex) 없음.
- 시트가 포커스를 잡고 있을 때 스낵바(되돌리기)에 키보드로 갈 수 없음, 삭제 후 포커스 복귀 없음.
- 다크 모드 토글 손잡이와 트랙 대비 약 2.6:1(비텍스트 3:1 미달).
- 실제 한글 IME에서 단축키(`isComposing`) 동작, 설치형 PWA·서비스 워커 갱신, maskable 아이콘 안전 영역을 실기기에서 확인.
