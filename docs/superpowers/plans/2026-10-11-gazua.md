# 가즈아 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 관심종목을 한 차트에서 비교하는 모바일 우선 정적 웹앱(GitHub Pages)과, 증권사 API를 중계하는 프록시를 만든다.

**Architecture:** Svelte 5 + TypeScript SPA. 화면은 `MarketDataProvider` 인터페이스(KIS·토스·데모)만 보고, 시장 세션·KRX 우선 거래소 선택·지표는 순수 함수 모듈로 분리해 TDD한다. 프록시는 핸들러 하나를 Cloudflare Worker(KIS)와 Node 컨테이너(토스, 고정 IP)에서 같이 쓴다.

**Tech Stack:** Node 22, pnpm 10 (workspace), Vite 6, Svelte 5(runes), TypeScript 5, Vitest 3 + @testing-library/svelte + jsdom + fake-indexeddb, Lightweight Charts 5, idb 8, Pretendard(npm, 번들), vite-plugin-pwa, fflate(유니버스 빌드), Wrangler 4, Playwright + @axe-core/playwright.

**Spec:** `docs/superpowers/specs/2026-10-11-stock-compare-design.md` (화면 목업: `docs/design/2026-10-11-mockups.html`)

## Global Constraints

- 서비스명 `가즈아`, 저장 키 접두사 `gazua:v1:`, IndexedDB 이름 `gazua-cache`, Pages 경로 `/gazua/`.
- 모든 시각 계산은 **KST 고정**. 테스트는 항상 `TZ=America/New_York`으로 돌린다(기기 시간대 독립성 검증).
- 자동 거래소 선택은 **KRX 우선**: `KRX 접속매매 중 → KRX, 아니면 NXT 접속매매 중 → NXT, 아니면 거래 불가`. 이 원칙은 코드 어디서도 바꾸지 않는다(세션 데이터만 바뀐다).
- 기간: `D1`, `W1~W4`, `M1~M6`, `Y1`. **1일만 1분봉**, 나머지는 전부 일봉. 봉 집계 로직은 만들지 않는다.
- 등락률 기준값 = 기간 시작 직전 거래일의 **KRX 종가**. NXT·통합 시세도 같은 기준값.
- 한 그룹(=한 차트) 최대 **8종목**. 색 슬롯은 종목에 붙고 정렬·필터로 바뀌지 않는다.
- 시리즈 색(슬롯 1→8) 라이트 `#eb6834 #1baf7a #4a3aa7 #eda100 #e87ba4 #008300 #2a78d6 #e34948`, 다크 `#d95926 #199e70 #9085e9 #c98500 #d55181 #008300 #3987e5 #e66767`.
- UI 토큰은 스펙 8.2 표 값 그대로. 상승·하락은 항상 ▲▼ 기호 동반. 강조색은 보라(`#5b47e0` / `#8b7bff`).
- 런타임 외부 스크립트·폰트 로드 금지(전부 번들). CSP: `default-src 'self'; script-src 'self'; connect-src 'self' https:; img-src 'self' data:; style-src 'self' 'unsafe-inline'`.
- 키·토큰은 로그·오류 메시지·URL에 넣지 않는다. 프록시는 주문·계좌 경로를 `403 proxy-path-blocked`로 거절한다.
- UI 문구는 존댓말 `~해요`체. 스펙에 나온 문구는 그대로 쓴다.
- v1 지표: 등락률, 고점 대비 하락률, 시장 대비 초과수익, 상대 거래량, 시가총액. (변동성·RSI는 v1.1 — 지표 시트에 비활성으로만 노출)

## Review Focus

1. **휴장일·주말에 1일 차트를 열 때** — 오늘(2026-10-11 일요일)처럼 장이 없으면 최근 거래일 데이터를 보여주고 헤드라인에 날짜를 붙여야 한다. → Task 13 `loadSeries` 테스트 `D1 on a holiday shows the latest trading day`.
2. **그날 봉이 하나도 없는 종목(신규 상장 전·종일 거래정지)** — 차트가 깨지지 않고 그 종목 행에만 `데이터 없음`이 떠야 한다. → Task 13 테스트 `empty candles yield an empty series without throwing`, Task 18 테스트 `leaderboard row shows 데이터 없음`.
3. **localStorage에 깨진 JSON이 들어 있을 때**(수동 편집·이전 버전) — 앱이 죽지 않고 그 키만 기본값으로 되돌린 뒤 배너로 알려야 한다. → Task 4 테스트 `corrupted JSON falls back to defaults and reports`.
4. **토큰 동시 발급 경쟁** — 여러 요청이 동시에 401·만료를 만나면 토큰 발급은 한 번만 나가야 한다(KIS는 1분 1회 제한). → Task 10 테스트 `concurrent authenticate calls share one token request`.
5. **KIS 분봉 시각 해석**(`stck_cntg_hour`가 봉 시작인지 끝인지 문서로 확인 불가) — 잘못 해석하면 세션 경계에서 봉이 1분 밀린다. → Task 11에서 시각 해석을 `KIS_MINUTE_TIME_IS_BAR_END` 상수 하나로 격리하고, Task 21 실연결 점검표 1번 항목으로 실제 값을 확인한다.
