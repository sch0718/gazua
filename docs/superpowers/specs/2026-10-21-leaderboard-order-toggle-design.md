# 리더보드 정렬 전환(값 순 / 내 순서) 설계

작성 2026-10-21. 기반 스펙은 [비교 화면 설계](2026-10-11-stock-compare-design.md) 7.2-6·7이다.

## 1. 문제

리더보드는 늘 지표 값 내림차순으로 줄을 세운다. 행을 길게 눌러 끌거나 `Alt+↑↓`로 옮기면 그룹 종목 순서(`group.items`)는 바뀌지만, 리더보드는 곧바로 값 순으로 되돌아가 끈 결과가 보이지 않는다. 바뀐 순서는 PC 레일의 `<그룹> 종목` 목록에서만 보인다. 모바일에서는 보이는 곳이 없다.

## 2. 대화에서 정한 것 (2026-10-21)

선택지 넷(그대로, (a) 정렬 전환, (b) 끌기 없애기, (c) 레일에서만 바꾸기)을 미리보기로 비교했고, **(a) 정렬 전환**으로 정했다.

## 3. 동작

### 3.1 정렬 전환
- 리더보드 머리줄에 `값 순` / `내 순서` 두 버튼(토글 그룹, `aria-pressed`)을 둔다. 그룹 이름은 `정렬`.
- **값 순**(기본): 지금과 같다. 지표 값 내림차순, 스크럽·키보드 포커스 중에는 순서 고정. 머리줄 글은 `등락률 순 · 4/8`.
- **내 순서**: 그룹 종목 순서(`group.items`, 추가한 순서 또는 끌어 바꾼 순서) 그대로 보인다. 값이 바뀌어도 행이 움직이지 않으므로 스크럽·포커스 고정은 쓰지 않는다. 머리줄 글은 `내 순서 · 4/8`.
- 고른 정렬은 프로필 설정 `Settings.boardOrder`(`'value' | 'mine'`, 기본 `'value'`)에 저장한다. 모든 그룹에 같이 적용한다. 저장된 값이 틀리면 다른 설정 필드처럼 기본값으로 바꾸고 저장소 배너로 알린다. 예전 저장 형식(필드 없음)은 알리지 않고 기본값.

### 3.2 순서 바꾸기
- **내 순서**에서만 길게 눌러 끌기(500ms)와 `Alt+↑↓`가 순서를 바꾼다. 끈 결과가 리더보드에 바로 보인다.
- **값 순**에서 길게 누르거나 `Alt+↑↓`를 누르면 순서를 바꾸지 않고, 리더보드 아래 상태 줄(`role="status"`)에 `값 순에서는 순서를 바꿀 수 없어요 · 내 순서에서 바꿀 수 있어요`를 4초 보인다. 길게 누른 뒤 뗀 click은 상세를 열지 않는다(끌기와 같음). 정렬을 바꾸면 안내를 지운다.
- `Alt+↑↓`로 옮긴 행은 포커스를 잃지 않는다(기존 포커스 되돌리기).

## 4. 범위 밖
- PC 레일 목록에서의 순서 바꾸기, 그룹별로 다른 정렬은 넣지 않는다.
