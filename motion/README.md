# 모션 데모

`gazua-demo.html`은 가즈아의 주요 화면 동작을 가상 손가락이 직접 조작하듯 보여주는 모션 그래픽입니다. 파일 하나로 동작하며, 모든 시세·종목 정보는 가상 데이터입니다.

- **재생**: 브라우저로 열면 바로 시작해 13단계를 자막과 함께 보여주고, 끝나면 2.5초 뒤 처음부터 반복합니다.
- **멈춤**: 화면을 누르거나 키보드로 조작하면 멈추고 직접 조작할 수 있습니다. 하단 도크의 시각 슬라이더·`⋯` 설정도 조작으로 보고 멈춥니다. 반복 대기 중에도 예약 재생이 취소됩니다. 하단 `▶ 데모 재생`으로 다시 시작합니다.
- **멈추지 않는 입력**: Shift·Cmd·Ctrl·Option 같은 수정키와 이를 조합한 단축키(녹화 `Shift+Cmd+5`, 전체화면, 확대 등)는 조작으로 보지 않습니다.
- **화면 크기**: 창 폭에 따라 모바일(600px 미만)·태블릿·PC(1024px 이상) 배치로 바뀝니다. 모바일 화면으로 보려면 Chrome 개발자 도구의 기기 모드(375×812)를 쓰세요.
- **영상으로 남기기**: macOS `Shift+Cmd+5` 화면 기록으로 녹화합니다.

원본은 [`../poc/gazua-poc.html`](../poc/gazua-poc.html)입니다(같은 코드에 `window.GAZUA_MOTION = true`만 켠 사본). PoC를 고치면 이 파일도 다시 복사하세요.

회귀 테스트: 저장소 루트에서 Node 22로 `node --test tests/demo.test.mjs`를 실행합니다.
